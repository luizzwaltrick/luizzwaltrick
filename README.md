Data professional with ~2 years working across the full data lifecycle: extraction (SQL Server, PostgreSQL), transformation and automation (Python), data modeling and Power BI dashboards. 📍 Santa Catarina, Brazil · 🇬🇧 English C1.

- 📊 **Sole data analyst at ALS Logística** — built and maintain **25+ Power BI dashboards** used by every area (Board, Finance, Operations, Fleet, HR, Sales).
- 🧾 Built the company's **unified P&L (DRE)** with complex SQL Server consolidation queries, plus daily SQL data-quality checks.
- 🗂️ **100% of reports versioned in Git (PBIP)** with build/publish scripts, a custom theme and custom visuals (pbiviz / TypeScript).

- ⚙️ Python automations that removed **500+ hours/month** of manual work.
